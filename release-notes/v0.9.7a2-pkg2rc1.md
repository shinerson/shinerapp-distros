# SHINER 0.9.7a2 — packaging 2~rc1 — UAT prerelease

These three Linux candidates are published for recipient UAT. Application version
remains 0.9.7a2. This separate prerelease preserves the existing v0.9.7a2 release.

Application source: `0eb6e81d0db2763ed82dbe2481a3ea97dcc59a2d`.
Packaging synchronization: `9b525020710c66b8d21197811880b4648305a101`.
The six candidate builder/test files exactly match the synchronized Git blobs;
the synchronization changes only those six files relative to the approved source.

Packaging corrections add revision validation, overwrite protection, sanitized
wheel-build environments, offline named installation, and relocated script RECORD
repair. DEB version: `0.9.7~a2-2~rc1`; RPM: `0.9.7~a2-2~rc1.fc42`.

## Outstanding native UAT

Installation, startup, upgrade from the existing public release, removal, and
user-data preservation have NOT been validated on Ubuntu 26.04, Debian 13, or
Fedora 42. Native Python 3.13 execution on Debian/Fedora remains pending.
Ubuntu requires Python 3.14; Debian/Fedora require Python 3.13.
No native UAT success or package signing certification is claimed.
