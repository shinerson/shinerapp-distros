## Included corrections

- **UI-MOUSE-01:** Help and Platform Doctor retain declared menu mouse targets
  after operations. Protected online-assessment consent remains keyboard-only;
  returning to the menu restores mouse eligibility. AUTO/HOVER/CLICK/OFF and
  keyboard behavior are preserved.
- **DOCTOR-KICAD-01:** GUI discovery no longer executes `kicad --version` or
  `pcbnew --version`. Version evidence uses `kicad-cli version`; external discovery
  commands have bounded timeouts and failed probes are reported.
- Current application documentation and offline Help are included.
